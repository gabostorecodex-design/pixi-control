# Privacidad visual

PIXI solicita `CAMERA` al activar las funciones de visión. Las imágenes no se guardan por defecto. Cada análisis envía únicamente el fotograma actual al Worker configurado y luego a OpenRouter. Cerrar la cámara libera inmediatamente los recursos.

La memoria visual permanente está desactivada. No existe guardado silencioso de fotografías.
