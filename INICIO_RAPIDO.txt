PIXI V8.4 - INICIO RAPIDO

1. Arduino IDE: instala esp32 by Espressif Systems.
2. Instala LovyanGFX.
3. Instala NimBLE-Arduino de h2zero.
4. Abre PIXI_CYD_V8_LIFE_HTTPS_BLE.ino.
5. Placa: ESP32 Dev Module.
6. Flash 4MB, PSRAM Disabled, Upload 115200.
7. SUBIR.

LOCAL:
Wi-Fi PIXI-AI
Clave pixirobot
192.168.4.1

HTTPS:
El proyecto trae github-pages/ y workflow para GitHub Pages.
Repo sugerido: pixi-control
URL esperada:
https://gabostorecodex-design.github.io/pixi-control/

En Android Chrome:
1. Abre la URL HTTPS.
2. Pulsa CONECTAR A PIXI.
3. Elige PIXI por Bluetooth.
4. Pulsa TOCA Y HABLA.
5. Acepta el permiso del microfono.
