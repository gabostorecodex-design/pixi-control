PIXI V8.6 - COMO SUBIR A LA ESP32 DESDE ARDUINO IDE
================================================

1. Instala en Arduino IDE:
   - esp32 by Espressif Systems
   - LovyanGFX
   - NimBLE-Arduino by h2zero

2. Abre:
   PIXI_CYD_V8_LIFE_HTTPS_BLE.ino

3. Selecciona:
   Board: ESP32 Dev Module
   Puerto: el COM que aparezca al conectar tu CYD/ESP32

4. Ajustes recomendados:
   CPU Frequency: 240 MHz
   Flash Frequency: 80 MHz
   Flash Mode: QIO
   Flash Size: 4MB
   PSRAM: Disabled
   Upload Speed: 115200
   Partition Scheme: Minimal SPIFFS (1.9MB APP con OTA) recomendado

5. IMPORTANTE:
   El archivo LGFX_CYD.hpp debe estar en la misma carpeta que el .ino.

6. Pulsa primero Verificar.

7. Si compila correctamente, pulsa Subir.

8. Tras arrancar:
   Wi-Fi: PIXI-AI
   Clave: pixirobot
   Web local: http://192.168.4.1

9. Para la web HTTPS del micrófono:
   - Sube TODO el proyecto a GitHub.
   - El ZIP ya contiene:
     github-pages/
     .github/workflows/pages.yml
   - Activa GitHub Pages usando GitHub Actions.

10. La carpeta github-pages contiene la interfaz HTTPS para:
    - micrófono del teléfono
    - voz TTS
    - Bluetooth BLE con Pixi
    - respuestas OpenAI GPT-5 nano mediante openai-worker/

11. Publica openai-worker/ siguiendo openai-worker/README.md. La API key de
    OpenAI debe guardarse como secreto del Worker y nunca dentro del .ino o la web.

ARCHIVOS CLAVE
--------------
PIXI_CYD_V8_LIFE_HTTPS_BLE.ino  -> firmware principal
LGFX_CYD.hpp                    -> pantalla/touch CYD
README_CODEX_PIXI.md            -> instrucciones completas para Codex
platformio.ini                  -> compilación alternativa con PlatformIO
github-pages/                   -> web HTTPS
openai-worker/                  -> servidor seguro para OpenAI
.github/workflows/pages.yml     -> despliegue automático de GitHub Pages
